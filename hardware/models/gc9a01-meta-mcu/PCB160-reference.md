# Provisional compatible-drawing revision

is a new working reference, not a replacement for the unchanged imported model.
See the [dimensional review](../../../enclosure/freecad/LCD-PCB160-review.md)
for evidence, uncertainty, datums, recipe, validation and integration consequences.

The user supplied dimensions from an additional compatible-module drawing;
the original drawing, URL, author, revision and license were not supplied and
were not available locally. No copy of that drawing is redistributed. Numerical
dimensions are recorded as provisional engineering evidence, not exact Dorhea
measurements. The 11.3 mm annotation remains unassigned.

META-MCU-derived header geometry and datum/outline assumptions retain the
upstream [EPL-1.0 license and attribution](NOTICE.md). The original STEP,
upstream license and normalized source remain unchanged and available in this
directory. Project changes: replacement native parametric PCB outline/thickness,
hole size, LCD body size, named drawing parameters, and explicit provisional
status. Editable construction source is
[create_lcd_pcb160_revision.py](../../../enclosure/freecad/create_lcd_pcb160_revision.py).
